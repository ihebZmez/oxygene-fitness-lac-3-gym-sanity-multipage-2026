# 01 — Project Overview

## Samurai Nouvelle Madina

Premium multi-page website for a Tunisian gym & sports club.

### Goal

Convert online traffic into:

- Trial-session requests
- Memberships
- Personal-training leads
- Corporate partnerships
- Partner-product sales

### Brand

Dark premium interface · orange accents · strong photography & video · restrained GSAP motion · clear CTAs.

### Audience

Prospects, members, personal-training clients, companies, coaches, sports-product partners.

### Status

React frontend, Sanity CMS, responsive pages, i18n and content hooks are implemented. Pre-launch: configure EmailJS, seed production content, complete SEO/analytics, run mobile QA.
