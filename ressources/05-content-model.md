# 05 — Content Model (Sanity)

All content is managed in Sanity Studio. Each document type maps to a section on the site.

| Document          | Purpose                              | Managed by |
| ----------------- | ------------------------------------ | ---------- |
| Site Settings     | Name, phone, WhatsApp, social, hours | Client     |
| News              | Club announcements                   | Client     |
| Promotions        | Time-limited offers                  | Client     |
| Activities        | Class catalogue                      | Client     |
| Coaches           | Team profiles                        | Client     |
| Class Schedule    | Weekly planning                      | Client     |
| Pricing Plans     | Membership tiers                     | Client     |
| Personal Training | 1-on-1 packages                      | Client     |
| Corporate Offers  | B2B offer                            | Client     |
| Partner Products  | Shop items                           | Client     |
| Testimonials      | Member quotes                        | Client     |
| Transformations   | Before/after results                 | Client     |

### Key Rules

- Every document has an **Active** toggle (publish without deleting).
- Promotions have `endDate` — expired offers hide automatically.
- Transformations require **consent** before publishing.
- Images are uploaded directly in Sanity — no file paths needed.
